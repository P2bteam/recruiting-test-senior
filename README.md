# recruiting-test

This test is divided into three stages: algorithmic understanding, code review, and code refactoring.

## Algorithms

### BFS

Complete the code in the `BFSUtils.php` class to implement a Breadth-First Search (BFS) algorithm.

The `bfs.php` file contains a dataset and a test used to validate the generated code.

The `Tree.png` file represents the data structure to be traversed.

### DFS

Complete the code in the `DFSUtils.php` class to implement a Depth-First Search (DFS) algorithm.

The `dfs.php` file contains a dataset and a test used to validate the generated code.

The `Tree.png` file represents the data structure to be traversed.

## Code Review

The `regles_codage.md` file describes the coding standards that must be followed.

Review the files and verify compliance with the coding standards, development best practices, and provide any additional feedback you consider relevant.

## Code Refactoring

The `Repository` class simulates a complete PDO implementation (exclude it from the refactoring).

### Objectives

* Improve code readability
* Standardize and harmonize the codebase
* Enable the implementation of new features without introducing technical debt
